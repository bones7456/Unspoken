Support

We're here to help with any questions or issues.

Contact Support

For the fastest response, email us at:

bones7456+unspoken@gmail.com

We aim to respond within 3 working days. For urgent safety or security matters, we prioritize response time.

When contacting support, please include your device model, iOS version, app version, and a clear description of the issue.

Common Topics

  • Connection issues or reconnect problems
  • Pinned room not persisting across restarts
  • Heart rate sharing not working (requires Apple Watch)
  • Image or meme sending issues
  • Reporting an abusive user
  • Feature requests or feedback
  • Self-hosting the server
